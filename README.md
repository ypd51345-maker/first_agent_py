# First AI Agent

我的个人 AI Agent 学习项目，使用 Python 探索 AI Agent 的基本架构与实现方式。

## 项目介绍

本项目用于学习和实践 AI Agent 的核心机制，包括工具调用、知识检索、记忆管理、任务规划和反思机制。

## 技术栈

- Python
- Chroma 向量数据库
- Git / GitHub

## 项目结构

| 文件 | 说明 |
|---|---|
| `agent.py` | Agent 主程序 |
| `tools.py` | 工具调用相关代码 |
| `rag.py` | 知识检索相关代码 |
| `memory.py` | 记忆管理相关代码 |
| `planner.py` | 任务规划相关代码 |
| `reflection.py` | 反思机制相关代码 |
| `calculator.py` | 计算工具 |

## 学习目标

- 理解 AI Agent 的基本工作流程
- 学习使用工具完成任务
- 探索 RAG 知识检索与记忆机制
